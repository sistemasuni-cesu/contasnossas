Configurar sincronização

Seus dados serão salvos em um arquivo financas.json no seu repositório do GitHub — acessível de qualquer dispositivo, com histórico automático de versões.

1
Acesse github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2
Em Repository access, selecione Only select repositories e escolha o repositório onde o app está hospedado. Em Permissions → Contents, escolha Read and write.
3
Gere o token, copie e cole abaixo. Ele fica salvo só neste dispositivo (localStorage) e nunca é enviado a nenhum servidor além do próprio GitHub.
O token fica salvo apenas neste navegador (localStorage). Os dados financeiros ficam no GitHub.
