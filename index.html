Configurar sincronização

Seus dados serão salvos em um Gist Secreto no GitHub — privado e acessível de qualquer dispositivo.

1
Acesse GitHub → Settings → Developer settings → Fine-grained tokens
2
Em Account permissions → Gists selecione Read and write. Não precisa selecionar repositório.
3
Gere o token e cole abaixo. O Gist Secreto será criado automaticamente na primeira vez.
🔒 Salvo apenas neste navegador. Seus dados ficam num Gist Secreto.
